# Product

## Register

product

## Users

Minecraft server owners, administrators, and plugin developers who need to install, configure, troubleshoot, and evaluate SmartSpawner quickly. They often arrive with a specific operational question and need a direct answer, a recognizable screenshot, or a working configuration example.

## Product Purpose

The documentation makes SmartSpawner easy to understand and operate across Java and Bedrock servers. Success means users can find the correct guide or interface screenshot quickly, understand the next action, and return to running their server with confidence.

## Brand Personality

Capable, direct, and community-built. The experience should feel technically trustworthy without becoming cold, and polished without distracting from the task.

## Anti-references

Avoid generic SaaS landing-page patterns, decorative Minecraft pixel-art that competes with documentation, dense wiki navigation with weak hierarchy, and visual effects that slow down scanning or obscure controls.

## Design Principles

- Put the next useful action close to the user's question.
- Show the product when a screenshot explains faster than prose.
- Keep familiar documentation patterns and make their hierarchy clearer.
- Treat English and Vietnamese as equally complete experiences.
- Use motion only to explain state and preserve user preferences.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support keyboard navigation, visible focus, semantic labels, sufficient contrast, responsive layouts, reduced motion, meaningful alternative text, and search behavior that does not depend on color alone.
